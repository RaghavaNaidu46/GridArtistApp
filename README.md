# Grid Artist — support

Support site and privacy policy for **Grid Artist**, an iPhone and iPad app that
turns any reference photo into a step-by-step drawing grid.

- Support: https://raghavanaidu46.github.io/GridArtistApp/
- Privacy: https://raghavanaidu46.github.io/GridArtistApp/privacy.html
- Bugs and feature requests: this repository's
  [issue tracker](https://github.com/RaghavaNaidu46/GridArtistApp/issues/new)

The app collects no data. Everything — including the on-device Vision and Core
Image features — runs locally.
